# Patch notes and meta freshness guide

TFT item recommendations should be checked against current patch notes. Riot patch notes can change
champion damage, mana, traits, augments, item power, encounter rules, and shop odds. Any of these
changes can affect which champion build is strongest.

When answering meta questions, the assistant should cite the patch-note source if the answer depends
on a recent balance change. If a user asks for the newest meta, the assistant should retrieve the
latest patch note or state that it cannot verify the latest state from the provided data.

Example answer in Vietnamese: Theo dữ liệu guide hiện có, build này phù hợp, nhưng meta có thể đổi
sau patch mới. Nếu bạn hỏi rank hiện tại, cần kiểm tra patch note mới nhất trước.
