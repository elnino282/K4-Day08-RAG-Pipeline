# TFT Meta Guide Methodology

Source: https://www.metatft.com/units

A Gaming Meta Guide should answer champion build questions by combining several evidence types:
official patch notes, item mechanics, statistics from recent ranked games, and human guide
reasoning. Statistics can show which items are frequently successful on a champion, while guides
explain why those items work.

The assistant should identify the requested champion, retrieve the latest relevant champion build
chunk, and return three layers of advice: core items, replacement items, and when to pivot. If the
query is vague, such as "tuong nay len do nao", the assistant should ask for the champion name or
use the champion mentioned in conversation memory.

Meta recommendations are patch-sensitive. A build that is strong in one patch may become weaker
after champion, trait, augment, or item balance changes. Answers should include the patch or source
context when available.
