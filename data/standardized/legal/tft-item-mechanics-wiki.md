# TFT Item Mechanics Wiki Summary

Source: https://wiki.leagueoflegends.com/en-us/TFT:Item

TFT item mechanics determine how build recommendations should be interpreted. Champions can hold up
to three items. If a champion is sold, the equipped items are returned. When units combine and would
exceed the item limit, extra items are dropped back to the player.

Item stacking depends on the item. Some effects stack additively, but some items or unique effects
do not stack with themselves. A good build guide should recommend a core item package and explain
alternatives instead of blindly stacking the same item.

Item recommendations should account for the champion's role. Attack damage carries usually value
attack damage, attack speed, critical strike, armor penetration, or sustain. Magic damage carries
usually value ability power, mana generation, magic penetration, and critical spell damage.
Frontline tanks usually value health, armor, magic resistance, shields, and healing.
